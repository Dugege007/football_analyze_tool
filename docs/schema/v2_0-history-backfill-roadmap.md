## 执行摘要（约 10 行）

1. **北极星**：数据就绪后做**尽可能宽**的 as-of 走前影子（一年只是举例，不是上限）。  
2. **赛程/赛果（P0）**：体彩汇总已有约 **84599** 场，清单侧基本够；缺口主要在 fixture↔5DF 对齐队列落盘。  
3. **P1 主线**：竞彩约 **5034** 场 × 澳门+平博 AH 开/中/收；剩余约 **4857** 场 × **3** 次 ≈ **14571** 调用 ≈ **8.1 h**（≤30/分）。  
4. **若今晚开队列**：P1 估计 **10-07 夜～10-08 晨** 可跑完（错峰则拉到当日白天）。  
5. **P2**：Bet365/皇冠/威廉等剩余 AH；相对完整档再约 **半～1 天**墙钟（约再 **8 h** 量级）。  
6. **P3**：竞彩胜平负可搭 5DF；**让球胜平负 5DF 无**，须 sporttery 等通道（另排，勿忘入库）。  
7. **P4**：大小球／欧赔按未来方案需要再开队列，不与 P1 抢额度。  
8. **P5**：P1 验收过 + 铁律/泄漏清单过 → 才开**大范围**走前影子；当前短影子只是过渡。  
9. **现计划不改则停滞**；必须新建 `5df-multibook-history-queue`，勿原样恢复已空转的 Bet365 续拉。  
10. **巡检**：队列跑着时每 **2–4 h** 查深度／错误率／落库口径／双写仍关。

## 4. 巡检（脚本跑着时）

| 项 | 约定 |
|---|---|
| **频率** | 队列**活跃时每 2～4 小时**；空闲日改每日一次 |
| **必查** | ① 队列深度／pending 是否下降；② 错误率与 `X-RateLimit-Remaining`（≤5 停）；③ 落库是否副本、字段／`market`／`book` 符合 schema；④ **`DUAL_WRITE` 仍关**；⑤ mid 推导未用本场赛果；⑥ 与赛前硬窗是否撞车 |
| **异常** | 连续空轮或错误飙升 → 停队列、修脚本、记日志后再启；不默默换源绕过铁律 |
| **负责人** | 分析师主导巡检；脚本告警；后端协助库侧 |

## 5. 风险／阻塞

| 风险 | 影响 | 应对 |
|---|---|---|
| **无多庄年回补队列**（旧 Bet365 续拉已空且勿原样恢复） | 现计划下一年 AH **基本停滞** | P1 启动条件：新建 `5df-multibook-history-queue` |

| **InferSports feed stale** | 不能当临盘 | 降级归档；不占 mid 主指纹 |
| **让球胜平负无 5DF** | P3 HHAD 可能拖期 | 尽快定 sporttery 等通道；未定时公开标阻塞 |
| **5DF 竞彩编号自约 2025-10 中下旬** | 更早场对齐成本高 | 优先有编号窗；更早场降级或其它源 |
| **usage 已高的 UTC 日** | 与实时采集抢分钟 | 错峰；盯 remaining |
| **FA 月度断档／box 缺 2503–2605** | 旧 CSV 路径≠新 mid 路径 | 两条线分开验收，不互相替代 |
