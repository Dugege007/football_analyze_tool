# 「当日赛程」页预测方向列的格式建议稿（待用户确认）

状态：这是建议稿，所有格式都等待用户确认，本次版本（v0.1.3）没有实现这些列。

## 背景

用户在 2026-10-10 要求暂时去掉「当日赛程」页的「方向」列。以后计划改成五个预测方向列：「亚盘」「欧盘」「大小」「竞彩」「竞彩让球」。

## 共同规则

1. 每一列显示的方向，必须是当时确定下来的方案做预测时得到的方向，也就是正式库里冻结下来的预测。以后即使数据被修正、方案被改进，也不能事后重新计算并改写这些方向。
2. 某个方向不下注时，这一列显示「-」。
3. 某个方向下注时，这一列按下面各自的格式写出方向。
4. 一场比赛使用了多个正式方案时，每个方案的方向分别显示，并标明对应的方案代码。

## 各列格式建议

| 列名 | 建议格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 亚盘 | 「主」或「客」，后面跟这一方所受的让球数 | 「主 -0.5」「客 +0.25」 | 让球数写成这一方的视角，负数表示让球，正数表示受让。 |
| 欧盘 | 「主胜」「平局」或「客胜」 | 「主胜」 | 欧盘是不含让球的胜平负。 |
| 大小 | 「大」或「小」，后面跟大小球的盘口 | 「大 2.5」「小 2.25」 | 盘口按总进球数写。 |
| 竞彩 | 「胜」「平」或「负」 | 「胜」 | 指竞彩胜平负玩法，按主队的结果写。 |
| 竞彩让球 | 「让胜」「让平」或「让负」，后面用括号写主队的让球数 | 「让胜(-1)」「让负(+1)」 | 指竞彩让球胜平负玩法，按主队让球后的结果写。 |
