# 方案工场 · 设计草案（未实现 API 不写成已上线）

> 状态：**设计稿**。M1 仅导航占位；表结构与 API 待 M2+ 由后端出正式 migration / OpenAPI。  
> 关联：`analysis-tool-roadmap-20261006.md` §10、`data-conventions-v1.md`、现网 `predictions` / `prediction_legs`。

---

## 1. 目标

让用户在 WebUI 中**自由排列组合**机构 / 时段 / 特征 / 门槛 / 状态机等，确认后生成带版本号的**方案定义**；可对历史做多种形式验证，结果按指纹缓存；支持多方案对比与**方案叠加**统筹。

日用白名单仍克制：只有长期验证过关的方案才进预测派单。

---

## 2. 核心对象（逻辑模型，非已建表）

### 2.1 `strategy_defs`（方案定义）

| 字段（草案） | 说明 |
|---|---|
| `strategy_id` / `version` | 唯一版本键，如 `CFFXDJ_5_V3` 或新方案 `AH_STACK_V1` |
| `market` | `ah` / `ou` / `1x2` / `jc_hhad` … |
| `config_json` | 机构池、时段（初/中/临）、特征族、参数、组合规则、状态机模板引用 |
| `status` | `draft` / `research` / `shadow` / `paper` / `whitelist` / `archived` |
| `created_at` / `notes` | 溯源 |

**原则**：配置驱动；新增玩法优先扩枚举与 JSON schema，不硬编码分支。

### 2.2 验证缓存（fingerprint）

| 字段（草案） | 说明 |
|---|---|
| `strategy_id` + `version` | 方案 |
| `validation_kind` | 如 walk-forward / 同桶 / 滚动周 … |
| `data_fingerprint` | 输入数据范围哈希（比赛集、盘口版本、结算口径） |
| `params_fingerprint` | 验证参数哈希 |
| `result_json` / 汇总指标 | ROI、回撤、样本数、资金曲线点等 |
| `computed_at` | 计算时间 |

**命中规则**：同方案 + 同验证形式 + 同数据/参数指纹 → **复用**，不重算全历史。

### 2.3 对比与叠加

- **对比（compare）**：多选已有方案，同一折线图叠历史盈利趋势；可附回撤、胜率、样本数。
- **叠加（stack / portfolio）**：多方案并行下注；可统一注额策略或各自策略；输出组合资金曲线，便于统筹规划。  
  日 10 份等敞口上限只约束「实盘敞口」那一次调用（与现网 `/bankroll/calc` 口径一致：多策略对比分开算）。

## 3. 与现网关系

| 现网（已落地） | 方案工场 |
|---|---|
| `predictions`（亚盘，`CFFXDJ_5_V3`） | 可登记为 whitelist 基线，只读对照 |
| `prediction_legs` | 多玩法腿入库目标表；工场产出可写入 |
| `/bankroll/calc`（v1.2） | 叠加/对比时的注额换算可调用；工场不改其规则 |
| 队名别名 / `kickoff_at` | 消息与图表展示用规范名 |

**未经用户同意不改 V3 默认。**

## 4. 阶段落地（与路线图对齐）

| 阶段 | 后端 | 前端 |
|---|---|---|
| M1 | 不动现网；可选文档占位 | `/schemes` 等导航占位 |
| M2 | `strategy_defs` + 验证缓存 **DDL 草案** + OpenAPI 草稿 | 列表只读（若 API 未就绪则 mock 关闭） |
| M3 | 定义 CRUD + 生成可执行配置；状态机模板 | 编排器 MVP |
| M4 | 验证任务 + 缓存命中；compare/stack 聚合查询 | 对比/叠加折线图 |

## 5. 扩展点（预留）

- 机构池扩展：澳门/皇冠/威廉/平博/Bet365/竞彩 + 机构均值交叉核对（先研究闸门）。
- 大小/欧赔：机构不全或变动少 → 仅初盘或初+临；竞彩字段只走竞彩源。
- 新特征族、新组合花样 → 进 `config_json`，经影子→纸面→小注。
- 汇率展示：现网 `fx_*` 占位，换算后接。
