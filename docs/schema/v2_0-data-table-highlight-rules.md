# 数据表页 · 自动高亮口径 v0（2026-10-08，足球分析师定）

颜色（用户定）：升盘红字、降盘绿字，都不填充；风险填充 黄=轻、橙=中、红=严重。
所有阈值集中放前端配置，带版本号 `hl_v0.1`（2026-10-08 由 hl_v0 升版：收紧公司分歧阈值，补上 §8 的细则，初盘改按各公司首开）；改阈值即升版本，不改历史口径说明。
返还率、凯利由后端统一计算；前端只读结果和阈值。

## 0. 通用口径
- 用词以 `v2_0-odds-phase-terminology.md` 为准：初盘/中盘/临盘分列，其他时刻快照标「即时（抓取时间）」。
- 机构：澳门、皇冠、威廉 + **平博**（用户唯一有资金的账户，必须在表里）。
- 盘口方向：按「让球方」看。让得更多=升盘（红字），让得更少=降盘（绿字）。
- **换边**（让球方变了，如主让 0.25→主受让 0.25）：按降盘标绿字，并叠 **橙** 填充。
- 「临盘」默认 = 规定临盘：开赛前 1h；开赛 ≥23:00（含次日凌晨）的场改为当天 22:00。初盘 = 各公司第一次开出的盘（`open`，带实际开盘时间）；11:10 快照作「即时（11:10）」对照列；中盘 = 开赛前 8h（≥23:00 场为 15:00，标「（规则）」；真实 T−8h 标「（真实）」）。≥23:00 场的临盘同样分「（规则）」22:00 和「（真实）」T−1h，前端留开关切换对照。
- 比较一律同一时间点、同一阶段（初/中/临）的快照；缺快照的格子留空不判。

## 1. 升降盘（临盘 − 初盘）
- |变化| ≥ 0.25：标字色（红升/绿降）。
- |变化| ≥ 0.50：再叠 **黄** 填充（大幅变盘，提醒看，不一定是风险）。
- 换边：叠 **橙**（见 §0）。

## 2. 水位异动（仅盘口不变时判；盘口变了水位会重置，不判）

> **0.3.18 / 第二批口径 F（后端字段）**：只认真实水位（`water_source=actual`）。亚盘 mid / close 格 `water_move_eligible=true` 才做异动上色；`false`（任一格非 actual）/ `null`（盘口变了或不可见）不上色。`water_source=tier_midpoint` 不上色、不进方案计算；同盘但档位变了 → `tier_cross={from,to,sides}`，悬停「跨档：X→Y（档位换算，幅度不精确）」。欧赔 / 竞彩格子 `x1x2.{book}.{phase}.water_source` / `jc_1x2.{phase}.water_source`，上色规则与亚盘一致，`null` 不上色。
- 取主水、客水变化的较大绝对值：≥0.10 轻（黄）、≥0.15 中（橙）、≥0.20 严重（红）。
- v0 先用这组数；补数库（澳门+平博一年约 4.5k 场）出分位后再按「各公司自己的分布」校准，目标大约 轻≈10% / 中≈5% / 严重≈2% 的场被标。

## 3. 公司分歧（同一时间点、同一阶段的盘口）
- 最大与最小盘口差 = 0.25：**不标色**，只在提示里显示；≥0.50：轻（黄）；≥0.75：中（橙）。平博与澳门反向仍标红。（hl_v0.1 收紧：实测 6 月七成多的场次会触发 0.25 的差值，标出来没有信息量。）
- 平博与澳门方向相反（一家主让一家客让）：直接 **红**。

## 4. 亚盘返还率 = 1 ÷ (1/(1+主水) + 1/(1+客水))（港盘水位）
- 各公司正常区间差很大（平博常年 0.97 上下，澳门约 0.94–0.95），所以**不用一刀切的绝对值**，按各公司自己的基准偏离来判：
  - 低于该公司基准 −0.015：轻；低于 −0.03：中；高于 +0.015：轻。
  - 基准 = 该公司**截至当日之前**的滚动中位数（as-of，不用当日及之后的数据）。
- 基准没算出来前的兜底绝对值：
  - 澳门/皇冠/威廉：<0.93 轻、<0.91 中、>0.97 轻。
  - 平博：<0.955 轻、<0.94 中、高位不标。

## 5. 欧赔返还率 = 1 ÷ (1/胜 + 1/平 + 1/负)
- 同 §4 的「按公司基准偏离」规则（−0.015 轻、−0.03 中、+0.015 轻）。
- 兜底绝对值：澳门/皇冠/威廉 <0.90 轻、<0.88 中；平博 <0.95 轻、<0.93 中。

## 6. 凯利指数 = 某公司赔率 × 基准概率（胜/平/负各一个）
- 基准概率**主用平博去水概率**（p_i = (1/odds_i) / Σ(1/odds)），平博是市场里最准的锚。
- 另出一列「多家平均」：澳门/皇冠/威廉/平博各自先去水，再取平均。只有 4 家，噪声大，标「参考」。
- 平博本身的凯利用「多家平均」基准算（不能自己比自己）。
- 判定（某公司某结果）：凯利 > 该公司当时返还率：轻（黄）；凯利 > 1.00：中（橙）。低凯利只显示不标色。
- 缺平博欧赔时退回多家平均基准，格子加角标说明。

## 7. 防泄漏提醒
- 页面只读展示，但所有「基准/分位/中位数」都按 as-of 算（只用当日之前），以后要把这些标记接进特征时可以直接复用，不用返工。

## 8. 细则（hl_v0.1，2026-10-08 确认前端的 7 处理解）
1. 平手变成有一方让球算升盘；有一方让球变成平手算降盘。
2. 换边的同时变化幅度达到 0.5 时，只标橙色，不再叠黄色。
3. 公司分歧按区间判断，下限包含、上限不包含；分档见 §3（v0.1 已收紧）。
4. 判断平博和澳门是否反向时，平手视为没有方向，不算反向。
5. 欧赔返还率没有偏高的兜底值，所以偏高不标。
6. 「多家平均」做成一组去水概率列，标「参考」。
7. 预测出单之后才出的盘口格子只加虚线下划线和提示，不覆盖原来的红绿字色。
- 每个返还率格子记 `baseline_method`：`empirical`（按该公司历史中位数）或 `fixed_fallback`（真实水位样本不足 20 场，用 §4/§5 的兜底阈值）。统计高亮命中时按这个字段分开看。（2026-10-08）

## hl_v0.2 修订（2026-10-08）：返还率上色只看真实水位
- 返还率高亮只对 `water_source` 为真实水位的格子生效。档位中点换算出来的水位（皇冠、威廉现网全部是这种）默认不上色。原因：中点换算的水位有系统性偏差，威廉常年低于 0.93，上色只会反映换算方法，看不出机构的真实抽水。
- 档位换算的格子照常显示数值，字体用灰色，悬停写「水位为档位中点换算，非真实水位」。前端保留「档位换算也上色」开关，默认关，只给人工排查用；打开后的颜色不进任何导出或方案计算。
- empirical 基准和固定兜底阈值同样只用真实水位来算，档位换算的场不进基准样本，计数也不算在「≥20 场」里。
- 现网等于暂时不上色。等 5DF 补的真实水位（副本里有）接进并列列，或者前向实时采集开始写真实水位，上色就会自然出现。
- 版本号从 hl_v0.1 升到 hl_v0.2，指纹记 `return_hl_water=real_only`。
- hl_v0.2 补充（2026-10-08）：§2 水位异动同样只认真实水位（`water_source=actual`）。tier_midpoint 不做异动上色，只在阶段之间换了档位时悬停注明「跨档：X→Y（档位换算，幅度不精确）」。欧赔格子也标 `water_source`，上色规则和亚盘一致，null 不上色。

## hl_v0.3 临时调整（2026-10-08 18:17，回应前端 0.3.18 的三处提问）
只影响显示上色，不进特征和策略。指纹 `hl=v0.3`。
1. 凯利轻档加余量：凯利减返还率不小于 0.02 才算轻，中档和重档的阈值同样往上抬 0.02。这是临时值，后面按真实水位做分位数校准，目标是每档触发的格子降到约 10–15%，校准完升 hl_v0.4。
2. 返还率兜底线按公司分开：每家公司的兜底线取它自己真实水位返还率的 P25，只用这场所在竞彩日之前的数据滚动算。样本少于 100 的公司不上色，显示灰字，悬停写「样本不足，暂不判断」。不再统一用 0.90。
3. 水位异动统一比初盘和临盘，按文档来。中盘只用来判断有没有换过盘：
   - 初盘和临盘的盘口不同，记 `tier_cross`，水位不比较，只在悬停里说明。
   - 初盘和临盘盘口相同、但中盘换过盘的（皇冠 19 格、威廉 11 格），水位照常比较和上色，另外标 `tier_cross_mid=true`，悬停写「中盘曾换盘，已回到初盘盘口」。
   - 后端的 `water_move_eligible` 按这三条重算。

### 凯利分位数校准定为 hl_v0.4（2026-10-08 18:18，采纳算法顾问意见）
- 「场次命中率」作废，不再作为凯利指标：三项里至少一项凯利高于返还率，这是数学上必然的。
- 用相对偏差 r = 凯利÷返还率 − 1，按主、平、客三项分开做分位数阈值。每项各自约 P85、P92、P97 对应轻、中、重三档，目标是每项都亮 10–15%。只用这场所在竞彩日之前的真实水位数据滚动算。
- 某一项样本少于 100，这一项显示灰字，悬停写「样本不足，暂不判断」。
- 后端给 `kelly_thr_{h,d,a}` 和 `kelly_n_{h,d,a}`，前端规则表按三项各存一套阈值。
- 0.3.19 先上 hl_v0.3（固定余量 0.02，作为过渡）。hl_v0.4 等分位数表算好以后，跟后端的 config_version 一起切。

### hl_v0.3 后端字段（API 0.3.19，2026-10-08）
- `config_version=hl_v0.3`，`config.hl="v0.3"`。只管上色：生成器 / 策略代码不读下面任何字段（测试 `tests/test_hl_v03_0319.py` 有静态检查）。
- 凯利：`config.kelly_highlight = {margin: 0.02, levels: {light: kelly − 返还率 ≥ 0.02, medium: kelly ≥ 1.02, heavy: null}}`。hl_v0.2 只有轻、中两档，重档原本没定义，这次仍为 null。
- 返还率兜底：每个 ah / x1x2 格 `fallback_p25`、`fallback_n`、`fallback_hl_eligible`（= n ≥ 100）。亚盘、欧赔分开算，按公司取 open+mid+close 三阶段合并的真实水位（`water_source=actual`）返还率，只用竞彩日严格早于本场的数据，不设窗口，线性插值；人工复核场不进。n < 100 仍给 p25，但 `fallback_hl_eligible=false`，前端灰字。旧 `config.return_rate_fallback` 留作对照。
- 水位异动：只在 close 格上判，open / mid 格的 `water_move_eligible`、`tier_cross`、`tier_cross_mid` 恒为 null。
  - 初、临同盘：两格都是 actual → `water_move_eligible=true`，否则 false。
  - 初、临不同盘：`water_move_eligible=null`，`tier_cross={kind:"line", from:{phase:"open", line, home, away}, to:{phase:"close", …}, sides:["line"]}`，只放悬停。

  - 同盘档位换算跨档：`tier_cross.kind="water_tier"`（初 → 临档位）。
- hl_v0.4（凯利按主 / 平 / 客分位数 `kelly_thr_{h,d,a}` / `kelly_n_{h,d,a}`）这版没上。
