# 赛果入库节奏（v2.0）

> 用户 2026-10-07 拍板：先按本建议执行；发现问题再调。  
> 与 fixture 消歧（开赛差 ≤90 分钟）无关；与 as-of / cutoff 防泄漏分开。

## 1. 写库闹钟（拉取）

| 步骤 | 时刻 | 动作 |
|------|------|------|
| 主拉 | 开赛 **+3 小时** | 第一次拉赛果 |
| 补拉 | 之后 **每 30 分钟** | 未齐则重试 |
| 截止 | 开赛 **+6 小时** | 仍空 → 挂日核对队列（次日上午 / football-data 周三·周日等） |

- 开赛后未满 +3h：**不拉**赛果。
- 入库门槛：`home_goals` / `away_goals` / `total_goals` / `wdl` 齐全，且状态为完赛，才写入。
- 取消 / 推迟 / 退款：单独标记，**不进**可结算赛果。

## 2. 分析可用（不改写库闹钟）

仍跟足球分析仓库 `analysis_window_cutoff` + 已拓宽早场特殊带：

- 普通场：同竞彩日只认开赛 ≤ **本场开赛小时 − 4** 的已完整赛果。
- 早场特殊带：按 `[00:00, 11:30]`（有分钟）拓宽口径；旧整点 0–10→21 点稳定可用语义保留作对照。
- **禁止**用「赛果写入时刻」去改特征窗或重算已冻结预测。

## 3. 与预测冻结

- 赛果只用于：**结算本场**、给**更早 cutoff 已允许**的后续场当历史。
- 已产出方向快照：**不得**因赛果入库回头改写。

## 4. 与赔率 / 消歧

- 赔率：初盘 / 中盘 / 临盘通道另表，无「赛果 phase」。
- 消歧：5DF↔竞彩开赛差 ≤90 分钟只用于对齐是否同一场，**不是**赛果延迟。
